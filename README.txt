GLITCH.SYS — محاكي الاختراق الآمن
=================================

التشغيل من الهاتف:
1) فك ضغط ملف GLITCH-Simulator.zip.
2) افتح index.html في متصفحك أو ارفع الملفات الثلاثة إلى محرر/استضافة مواقع ثابتة.
3) إذا كان تطبيقك لا يفتح HTML محليًا، استخدم محرر أكواد للهاتف يدعم معاينة HTML.

الملفات:
- index.html : بنية الموقع
- style.css  : التصميم
- script.js  : الأوامر والتفاعلات

أوامر الطرفية:
help, whoami, status, scan, decrypt, matrix, clear, date, about

رمز الأرشيف التجريبي: glitch

تنبيه:
هذا مشروع محاكاة للواجهة فقط. لا يخترق أجهزة أو شبكات، ولا يفحص جهازك فعليًا،
ولا يتصل بأي خادم، ولا يجمع بيانات. نتائج الفحص خيالية وليست تقريرًا أمنيًا.
الخطوط الخارجية قد تحتاج إنترنت؛ الموقع نفسه يعمل محليًا بعد حفظ الملفات.
